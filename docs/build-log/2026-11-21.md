# 2026-11-21: Day one, or: how we decided to build a wasp

- Picked the Phase 1 build: a sub-100 g quadcopter flown by hand signals.
- Settled the architecture: ESP32-S3 flight brain, IMU, 4-in-1 ESC, four 1104 7500KV motors,
  3-inch props, 2S LiPo, and a separate Raspberry Pi hand tracker.
- Made the sensible decision to simulate first and buy parts after. Past us will thank us.
  Present us already has motors and props in a shopping basket, so the discipline is a bit shaky.
- Set up MATLAB Online and wrote a 1-D hover model with a PID controller.
- Learned what Kp, Kd and Ki do. Kp pushes, Kd brakes, and Ki holds a grudge about being
  wrong for too long.
- Tested a controller that thought the drone was 90 g when it was really 110 g. Without Ki it
  hovered 2.5 cm too low forever. With Ki it worked it out and reached 1 m.
- Wiped the old GitHub repos and started fresh. Very satisfying.
- Named the project WASP. Acronym: Wave-Activated Sub-100g Platform. Yes, we reverse-engineered it.
- Next: check the motor thrust numbers before buying, then write the requirements in SysON,
  then rebuild the hover model in Simulink.
